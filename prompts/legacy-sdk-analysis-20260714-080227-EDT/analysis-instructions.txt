# Project Context
This file contains a stripped-down subset of the official eBay Trading API SDK.  It contains only code made by a human or AI, and no autogenerated code (like wsimport or otherwise).  There are lots of features unrelated to sending and receiving payloads from the API, and its unclear if these features are necessary.  It only supports up to Java 8 on desktop because there are dependencies on Swing.

### Our Goal
We are creating a new SDK targeting Java 11+ and Android that is modern and lightweight.

### Critical AI Instructions
1. Focus entirely on identifying and evaluating features.
2. Do not make code refactoring suggestions since the current code is being discarded.
